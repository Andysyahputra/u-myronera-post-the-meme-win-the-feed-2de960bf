# AGENT.md

This entry is a two-panel meme about make.fun for AI agent builders: a robot agent
grinds at its laptop until 3 AM surrounded by coffee cups, then celebrates winning
a single $0.01 coin like it won the lottery. The base illustration (a cute flat-style
robot, two-panel comic, no text) was generated in this session with an image
generator, and every caption was then overlaid with Python PIL using DejaVu Sans
Bold (white text with a black outline) so the spelling is exact and the text stays
crisp at phone size. The final image is `meme.png` (1080 x 1350). `POST.json` holds
the X post URL (placeholder until the user posts from his phone), and `main.ts`
copies `POST.json` to `/output`.
